# 密钥扫描 · 例外清单
#
# scan-secrets.mjs 扫到但**判定为误报**的东西，在这里登记一行。
#
# 格式：
#   <路径 glob> :: <规则 id> :: <理由>
#
#   · 路径 glob —— 相对扫描根。例：src/model/**、**/*.test.ts
#   · 规则 id  —— scan-secrets.mjs 里 PATTERNS 的 id，或
#                  secret-file / env-file
#   · 理由     —— 写清楚为什么这是误报。**必填**。
#
# ★ 这份清单本身进仓库，审的人看得见 —— 所以理由不能写「先放着」。
#   能修规则就别开例外：例外越多，扫描器越没人信。
#
# ★ 真泄了密钥的，正确做法**不是**在这里加例外，而是：
#   1. 去对应服务吊销 / 轮换那个凭据
#   2. 清掉 git 历史里的它（改写历史 + 强推）
#   删文件是不够的 —— 历史里还留着，抓取机器人几小时内就会扫到。
#
